# Copilot Studio IT-Ticket-Workflow Reviewer

Dieser Skill unterstützt die schrittweise Prüfung und Optimierung eines IT-Ticket-Workflows in Microsoft Copilot Studio.

## Verwendung

1. Öffne den gewünschten Knoten in Copilot Studio.
2. Zeige den JSON-Code des Knotens an.
3. Übergib den vollständigen JSON-Code an den Skill.
4. Der Skill erklärt die aktuelle Funktion, erkennt Fehler und nennt die Werte, die in der grafischen Oberfläche einzutragen sind.
5. Nach jeder Anpassung wird der aktualisierte JSON-Code erneut geprüft.

## Typische Startanfrage

> Prüfe diesen Copilot-Studio-Knoten und sage mir konkret, was ich in der Oberfläche verbessern muss: [JSON]

## Inhalt

- `SKILL.md`: vollständige Arbeitsanweisung
- `references/workflow-blueprint.md`: kompakter Zielablauf
